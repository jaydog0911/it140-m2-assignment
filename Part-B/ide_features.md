# Assignment 2-3 Part B – IDE Features Reflection

## Introduction
This was my first time using VS Code to write, run, and test a Python program, and I will admit it was pretty frustrating at times. I had problems getting everything to work correctly, and it took me longer than I expected, which resulted in me turning the assignment in late. Even though it was frustrating, working through the problems helped me understand VS Code better and taught me more than if everything had worked the first time. The three features that helped me the most were the terminal, color highlighting, and the file explorer.

## Feature 1 – Terminal
The terminal was one of the most useful features for me because it let me run my Python program and see exactly what it was doing. I could enter a name and age and then see the program's output right there. When something did not work correctly, running it again helped me figure out whether the changes I made actually fixed the problem. I think the terminal will become even more useful as I learn more about Python and start writing bigger programs.

## Feature 2 – Color highligthing
The color highlighting in VS Code helped me tell the different parts of my Python code apart. Different things like variables, functions, strings, and numbers showed up in different colors, which made the code easier for me to read. As a beginner, I found this helpful because I am still learning what each part of the code does. It also made it easier to notice when something did not look right and gave me a better idea of where I might have made a mistake.
## Feature 3 – File Explorer
The File Explorer helped me keep track of all the different files and folders that were part of this assignment. At first, figuring out which file I was supposed to be working in was confusing, especially with the SDW, Python file, and the other assignment files. As I worked through it, I got better at using the File Explorer to move between files without getting lost. I can see this becoming even more important later when I start working on larger programs with a lot more files.
## Conclusion
Overall, this assignment was more frustrating than I expected, but I learned a lot from working through the problems instead of giving up on it. Being late with the assignment was not what I wanted, but getting everything working helped me understand VS Code and Python better than I did when I started. The terminal, color highlighting, and File Explorer all made different parts of the process easier. I still have a lot to learn, but I feel more comfortable using VS Code now than I did at the beginning.
